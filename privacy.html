Política de Privacidade — Mengão na Rede

Última atualização: 1 de novembro de 2026

Esta Política de Privacidade descreve como o aplicativo Mengão na Rede acessa, usa e armazena dados.

1. Sobre o aplicativo

O Mengão na Rede é uma ferramenta de uso pessoal que monta vídeos curtos de notícias do Flamengo e os publica no canal do YouTube do próprio titular da conta. O aplicativo não é oferecido como serviço a terceiros e não possui cadastro de usuários.

2. Dados do Google acessados

O aplicativo usa a API de Dados do YouTube (YouTube Data API v3) com as seguintes permissões:

  • youtube.upload — enviar vídeos para o canal do próprio titular;
  • youtube — ler informações básicas do canal e gerenciar os vídeos enviados pelo aplicativo.

O aplicativo não acessa Gmail, Drive, contatos, calendário ou qualquer outro dado da Conta Google.

3. Como os dados são usados

Os dados são usados exclusivamente para:

  • enviar os vídeos gerados ao canal do YouTube do titular;
  • ler o nome e o identificador do canal para confirmar a conta correta;
  • verificar o status dos vídeos enviados.

4. O que é armazenado

O token de autorização OAuth é armazenado localmente no computador do titular, em um arquivo protegido. Os vídeos, roteiros e metadados gerados também ficam armazenados localmente. Nenhum desses dados é enviado a servidores de terceiros pelo aplicativo.

5. Compartilhamento de dados

O aplicativo não vende, aluga, compartilha nem usa os dados do Google para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Retenção e exclusão

O titular pode revogar o acesso do aplicativo a qualquer momento em myaccount.google.com/permissions. Ao revogar, o token local deixa de funcionar e pode ser apagado do computador. Os vídeos publicados podem ser removidos diretamente no YouTube Studio.

7. Segurança

O acesso é feito por OAuth 2.0. O aplicativo não solicita nem armazena a senha da Conta Google. O token fica apenas no computador do titular.

8. Contato

Para dúvidas sobre esta política ou sobre os dados tratados, use o e-mail de suporte informado na tela de consentimento do aplicativo ou entre em contato pelo canal youtube.com/@mengaonaredeoficial.

9. Alterações

Esta política pode ser atualizada para refletir mudanças no aplicativo. A data da última atualização será sempre indicada no topo desta página.
